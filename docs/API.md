# Documentation

## Getting Started

This project provides tools for analyzing IPL cricket data.

## API Reference

### Data Loader

- `load_match_data(filepath)`: Load match data from CSV
- `load_player_data(filepath)`: Load player data from CSV

### Analysis

- `calculate_team_stats(match_data)`: Calculate team statistics
- `calculate_player_stats(player_data)`: Calculate player statistics
