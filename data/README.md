# IPL Data Directory

This directory contains IPL cricket data files.

## Data Sources

Add your IPL data files here in CSV format.

Example data files:
- `matches.csv` - Match details
- `deliveries.csv` - Ball-by-ball data
- `players.csv` - Player information
- `teams.csv` - Team information

## Data Format

Ensure your data files follow the standard IPL dataset format.
